# 制度问答与人工确认 Agent

一个可在浏览器操作的制度问答 Agent，以差旅报销为演示场景。用户可以查询住宿标准、计算超额金额并核对制度出处；需要保存结果时，系统先展示文件预览，收到人工批准后才执行写入。

**技术栈：** Python · LangChain · LangGraph · FastAPI · SQLite · BGE · BM25 · HTML/CSS/JavaScript

## 演示流程

1. 打开工作台，选择「上海 · 730 元住一晚」并发送。示例制度规定上海住宿上限为每人每晚 **600 元**，预期算出超额 **130 元**，并注明制度出处。
2. 点「请求保存这份回答」，核对待写入的文件名和内容。此时文件尚未生成。
3. 先点「拒绝」，确认没有写入；再发起一次保存，点「同意保存」，到 `workspace_files/` 检查生成的文件。

## 技术实现

- **有依据的问答：** 对本地制度切片，结合 BGE 向量检索与 BM25 关键词检索召回候选，经 BGE 重排后把相关片段交给模型。金额计算由工具执行，回答中注明来源。
- **有状态的工具编排：** LangChain 封装聊天模型和工具，LangGraph 调度模型与工具节点。SQLite 分开保存聊天历史和流程检查点，用户确认后可从暂停处继续。
- **由后端控制写入：** `save_file` 执行前暂停，工作台展示预览并接收同意或拒绝。恢复接口不能代替写入确认；文件访问限制在工作目录内，保存不覆盖已有文件。
- **可追踪的执行过程：** 按会话记录模型调用、工具执行和确认状态，分别统计模型与工具耗时，便于排查失败和定位慢点。

## 验证结果

| 验证 | 结果 |
| --- | --- |
| 自动化回归 | **30 项通过**，覆盖检索流程、检查点、人工确认和 Web 接口。 |
| 真实模型用例 | **4/4 达到预期**：制度查询、改写提问、资料无依据时不猜测、拒绝保存后不写入。详见[评测记录](eval_cases.md)。 |
| 后端边界实测 | 目录外读取被拒绝；直接调用恢复接口无法绕过写入确认，测试文件未生成。 |
| 响应耗时 | 同一服务进程完成首次加载后，一次「制度查询＋金额计算」端到端实测约 **3–4 秒**。 |

`4/4` 是这组用例的通过数，不是模型准确率；耗时为单次实测，不是平均值。首次检索可能因本地模型初始化而明显更慢。

## 本地运行

在仓库根目录执行（以下命令适用于 PowerShell）：

```powershell
python -m pip install -r requirements.txt
Copy-Item .env.example .env
```

在 `.env` 中填写自己的 `API_KEY`、`BASE_URL` 和 `MODEL_NAME`，使用支持工具调用的 OpenAI 兼容接口。首次检索需要能下载 BGE 模型，或已有本地缓存。不要提交 `.env`。

```powershell
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

打开 [演示工作台](http://127.0.0.1:8000/) 或 [API 文档](http://127.0.0.1:8000/docs)。前端由 FastAPI 提供，不需要另开前端服务。运行回归测试无需启动 Web 服务：

```powershell
python -m unittest discover -v
```
